# 👥 User Management CRUD App

A simple and responsive User Management CRUD application built using **HTML, CSS, and JavaScript**. The application allows users to create, update, and delete user cards, while keeping all data saved using the browser's Local Storage.

## 🚀 Features

- ➕ Add New User
- ✏️ Edit Existing User
- ❌ Delete User
- 💾 Local Storage Support (Data persists after page refresh)
- 📱 Responsive User Interface
- 🖼️ User Image Preview using Image URL

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
